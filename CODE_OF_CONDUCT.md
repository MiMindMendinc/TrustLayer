# Code of Conduct

Michigan MindMend Inc. projects are built for practical, human-first technology. Contributors, users, and maintainers are expected to keep discussion professional, constructive, and safe.

## Expected Behavior

Examples of expected behavior include:

- treating people with respect
- giving clear, useful feedback
- staying focused on the project and its goals
- being honest about technical limits
- protecting private or sensitive information
- raising safety concerns responsibly

## Unacceptable Behavior

Unacceptable behavior includes:

- harassment, threats, or personal attacks
- publishing another person’s private information
- sharing real secrets, private logs, medical records, youth/family data, or credentials
- submitting harmful examples that increase real-world risk without a clear defensive purpose
- claiming clinical, legal, security, or compliance status without evidence
- intentionally bypassing safety protections without maintainer approval

## Sensitive Safety Context

TrustLayer involves LLM safety, PII redaction, and prompt-injection defense. Please keep examples synthetic whenever possible. Do not include real private data in issues, pull requests, test cases, screenshots, or logs.

## Reporting Conduct Concerns

Report conduct concerns privately to:

**michiganmindmendinc@proton.me**

For security vulnerabilities, follow `SECURITY.md` instead of opening a public issue.

## Enforcement

Maintainers may edit, close, remove, or reject contributions that violate this code of conduct or create unnecessary safety, privacy, legal, or reputational risk for the project.

This code is inspired by common open-source contributor standards and adapted for privacy-first AI safety projects.
