## What This Project Is

TrustLayer is a prototype safety gateway that sits between an application and an OpenAI-compatible model endpoint. It demonstrates PII redaction, jailbreak / prompt-injection checks, topic blocking, streaming passthrough, and local audit-log concepts.

It is built as practical, inspectable AI safety infrastructure — not as a black-box compliance product.
